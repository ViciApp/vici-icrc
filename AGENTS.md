# AGENTS.md

Entry point for every AI coding agent working in this repository (Claude Code, Cursor, Codex, Copilot, Aider and the rest). Read it before any change. It is short on purpose; the detail lives in [`docs/ai/`](./docs/ai/README.md).

## 1. What this repo is

`vici-icrc` is the VICI token, the scarce reward and coordination token of Vici: an ICRC-1/2/3 ledger and an index (official DFINITY wasm, no code here) plus one custom Rust canister, the **minter**, which is the ledger's minting account and keeps a set of reserve accounts topped up under caps and rate limits. The why is in [`README.md`](./README.md), [`TLDR.md`](./TLDR.md) and [`TOKENOMICS.md`](./TOKENOMICS.md); the minter's logic and API in [`src/minter/README.md`](./src/minter/README.md).

- **The minter creates money.** Whatever it mints is new VICI supply, and the 1,000,000,000 VICI commitment is enforced only by its reserve caps. Every change to `src/minter/src/**` is reviewed as if it moved funds. The rules are in [`docs/ai/domain.md`](./docs/ai/domain.md).
- **Never touch mainnet.** No `npm run deploy:prod`, no `reinstall:*:prod`, no `dfx ... --ic`, no `DFX_NETWORK=ic`. The owner deploys.
- **State survives upgrades by Candid encoding.** A field added to `State` or to a type it holds must decode from the old bytes, or `post_upgrade` traps. See [`docs/ai/patterns.md`](./docs/ai/patterns.md#stable-state).
- **Do not hand-edit** `src/minter/minter.did`: it is generated by `npm run did`. See [`docs/ai/governance.md`](./docs/ai/governance.md).

## 2. Commands

```bash
npm ci                         # prettier and plugins
npm run format                 # prettier, cargo sort, cargo fmt (nightly), shfmt
npm run lint                   # prettier check + scripts/lint.sh (what CI runs)
cargo test --locked -p minter  # unit tests; CI does not run them, you must
npm run did                    # rebuild minter.did after an API change
npm run build                  # minter wasm + downloaded ledger/index wasm
```

Tool versions and the tools `lint` and `format` need (cargo-sort, shfmt, shellcheck, zizmor, yq, candid-extractor) are pinned in [`dev-tools.json`](./dev-tools.json); `scripts/setup <tool>` installs one.

## 4. The standard

Every change follows the universal standard in [`AntonioVentilii/officina` `standards/code.md`](https://github.com/AntonioVentilii/officina/blob/main/standards/code.md). It is not repeated here; cite a rule by number and name ("rule 5, one value, one place"). What this repo adds:

1. **Amounts are base units, as `candid::Nat`, and never divided.** One VICI is `10^8` base units; the minter only adds, subtracts after a comparison, and compares. See [`docs/ai/domain.md`](./docs/ai/domain.md#units).
2. **Pure rules stay pure.** Validation and amount computation live in `services/reserve.rs` and take plain values: no `STATE`, no `time()`, no ledger calls. That is what the unit tests cover.
3. **Never hold a `STATE` borrow across an `await`.** Read a snapshot, release, call the ledger, then commit in a new borrow.
4. **Every mint takes the per-reserve lock** (`reserve_mint_inflight`), releases it on every exit path, and counts what it minted in `lifetime_minted` and `mint_events`. See [the mint pattern](./docs/ai/patterns.md#mint).
5. **Every endpoint has a guard**: `caller_is_controller` for anything that writes or mints, `caller_is_not_anonymous` for reads and previews.
6. **Errors are `MinterError` variants**, returned through a named result enum per endpoint (`scripts/lint.did.sh` rejects `Result` and `Result_N` in the `.did`).
7. **Clippy is pedantic and warnings are errors.** A lint that must stay off at one site gets `#[expect(lint)]` with a reason, never `#[allow]` (`allow_attributes` is denied).
8. **Time is nanoseconds, named `_ns`**, from `ic_cdk::api::time()`. A flow reads it into `now` and passes it to the pure rules; only `ledger::mint_to` reads its own, for the ledger's `created_at_time`.
9. **An upgrade of a live minter carries `Arg::Upgrade`.** `Arg::Init` on `post_upgrade` starts from an empty state. See [`docs/ai/domain.md`](./docs/ai/domain.md#upgrades).

## 6. Governance

- **Truth hierarchy**, highest wins: the code, then CI (`.github/workflows/**`), then [CODEOWNERS](./.github/CODEOWNERS), then `docs/ai/**`, then this file and the [standard](https://github.com/AntonioVentilii/officina/blob/main/standards/code.md#truth-hierarchy), then tool layers (`CLAUDE.md`, `.cursor/rules`, copilot instructions). On a contradiction, stop and ask.
- **Meta-update rule.** A PR that adds a pattern, a shared helper, a constant, an endpoint, a persisted field, a script, a policy or a workflow updates the matching `docs/ai/**` page in the same PR. The map of which page owns what is in [`docs/ai/governance.md`](./docs/ai/governance.md#meta-update-map).
- **Security and money bugs are not public.** This repository is public: a suspected flaw in minting, caps, locks, access or upgrades goes to the owner in private, never into a PR, an issue or a comment.
